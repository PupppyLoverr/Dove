Features

Everything an agent touches, in one place.

Dove is the workspace around the agent, not another agent. Chat, terminal, diff, browser and files share one thread, whichever CLI is doing the work.

Many agents, one window

Run Claude Code on one task and Codex on the next. Threads sort by what needs you: approvals first, then work in progress, then finished.

Worktrees by default

Every task can run on its own branch in its own git worktree, so two agents edit the same repo without colliding. Merge, push or open a PR from the thread.

Chat ⇄ terminal

Chat is the rich view with approvals, steering and usage. Flip to the agent's own TUI on the same session, then flip back. One process owns it at a time.

A side panel that is part of the work

Diffs, git history, a file viewer, an in-app browser and a terminal stay attached to each thread. Open a path:line link and you are there.

Browser control

Every agent gets Dove's browser tools over MCP: navigate, snapshot, click, type, scroll, screenshot. Drive the in-app browser or your own Chrome through the extension.

Generative UI

Agents answer with interactive cards: stats, charts, tables, checklists, toggles and choices. Your pick goes back as a normal message, so any harness can continue.

Office documents

Create, preview and edit PDF, PowerPoint, Excel and Word files in the side panel, then ask the agent to change the one you are looking at.

Paper design

Connect Paper so agents read your canvases and turn designs into code, with the live result one tab away in the browser.

Composio tools

Give agents GitHub, Linear, Slack, Notion and hundreds more apps through Composio, using your own key. Tools are injected into every harness.

Computer use

Let an agent see and operate desktop apps through the open-source cua-driver, with every action visible and stoppable.

A transcript that reads like a document

Markdown, tables, Mermaid diagrams, math and images render as they stream. Tool calls fold away. One ledger tracks cost across every agent.

Local-first

Native, fast and yours.

Dove is written in Rust on GPUI. There is no Electron shell and no web app pretending to be one. Projects, transcripts, settings and usage live in SQLite under ~/.dove.

  • GPU-rendered, idle at zero frames per second
  • Bring your own keys and subscriptions. No model bill from us
  • Apache-2.0. Read it, build it, fork it

Questions

Is Dove an AI model or an agent?

Neither. Dove is the development environment around the agents. It launches the CLIs you already use (Claude Code, Codex, Cursor, Gemini CLI and others), normalises their output into one event stream and gives each task a worktree, diff, browser and terminal.

Do I need to pay Dove to use my agents?

No. Agents run on your own subscriptions and API keys. The desktop app is free and open source. Paid plans only cover hosted sync, extra devices and team features.

Where does my code go?

Nowhere new. Dove runs on your machine and stores data in ~/.dove. Agents talk to their own providers as they would in a terminal. Remote control relays session events, not your repository.

How is this different from Cursor, Conductor or Warp?

Dove does not ship its own model or bind you to one vendor. It runs many different agents side by side in isolated worktrees, in a native Rust app, and adds the shared pieces they lack: diff review, browser control, generative UI, office documents and a mobile remote.

How does remote control work?

Sign in with a Woozlit account on the desktop and the iOS or Android app. The desktop publishes each session as a Loro CRDT document to a Cloudflare Durable Object; the phone subscribes, renders the transcript and sends commands back. The agent keeps running on your desktop.

Which platforms are supported?

macOS, Windows and Linux for the desktop app. The in-app browser uses each OS's native web view: WKWebView, WebView2 and WebKitGTK. Mobile apps are for iOS and Android.

Can I contribute?

Yes. Dove is Apache-2.0. Read CONTRIBUTING.md, pick an issue and open a pull request.
